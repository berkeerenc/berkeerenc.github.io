[■] physiovision/README.md Funded by TÜBİTAK 2209-A

PhysioVision: an AI-based physiotherapy platform

Team lead and backend architect

Problem
Physiotherapy exercises needed to be assessed remotely and automatically. Therapists had to be physically present at every session.
Solution
A web and mobile platform with patient, therapist and admin roles that tracks body pose in real time with MediaPipe and classifies exercises with an LSTM model.
My role
API design, the user role system, data modeling, model integration and the Docker deployment process.
Result
A working system that assesses movement in real time across 13 exercises with about 82% LSTM classification accuracy. Delivered together with a React Native mobile app.
  • Flask
  • PostgreSQL
  • Redis
  • TensorFlow
  • MediaPipe
  • Docker
  • React
  • React Native
